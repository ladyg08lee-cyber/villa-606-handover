Villa 606 Handover Document System

Privacy Policy

Effective date: 5 September 2026

This Privacy Policy explains how the Villa 606 Handover Document System uses Google account and Google Drive data when an authorized user connects the application to Google Drive.

1. Purpose of the application

The application is an internal project-document management interface used to organize, upload, and access Villa 606 handover documents, including PDF files and related project records.

2. Google account and Google Drive access

When a user chooses to connect Google Drive, the application uses Google OAuth to request permission to access Google Drive for the purpose of creating folders, uploading project files, and accessing files needed for the handover workflow.

3. Information the application may process

  • Google account authorization information needed to establish the signed-in session.
  • Google Drive file and folder metadata required to locate, create, organize, and upload project documents.
  • PDF files and other project documents that the user deliberately uploads through the application.
  • Local application preferences or document metadata saved in the user's browser for interface continuity.

4. How the information is used

Google user data is used only to provide the application's document-management functions. The application does not use Google user data for advertising, profiling, or sale.

5. Storage and transmission

Project files uploaded through the application are sent to the connected Google Drive account through the Google Drive API and are stored in Google Drive. The application is hosted as a static website and does not intentionally operate a separate application server that stores uploaded project files. Some interface information may be stored locally in the user's browser.

6. Sharing of information

The application does not sell Google user data. Access to project documents depends on the permissions of the connected Google Drive account and any sharing permissions configured in Google Drive. Users should only share files with authorized project personnel.

7. Security and user responsibility

Users are responsible for protecting their Google account, using the application only on trusted devices, and ensuring that uploaded documents are appropriate for the intended project folder.

8. Revoking access

A user may revoke the application's Google account access through their Google Account security settings. Revoking access may prevent Google Drive functions in the application from working until access is granted again.

9. Changes to this policy

This policy may be updated when the application's features, permissions, hosting, or data-handling practices change.

10. Contact
